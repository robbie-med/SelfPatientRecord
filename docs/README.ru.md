Локальная персональная медицинская карта с AI-ассистентом. Ваши данные хранятся в базе данных SQLite на вашем устройстве.

**Не является медицинским изделием. Не соответствует HIPAA. Не использовать в экстренных ситуациях.**

---

## Возможности

- **Входящие** — Вставьте любой медицинский документ (результаты анализов, выписка из больницы, рецепт). ИИ извлекает структурированные данные; вы подтверждаете перед сохранением.
- **Анализы и показатели** — Результаты, сгруппированные по панелям, графики динамики и объяснения 20 распространённых тестов простым языком.
- **Визуализация** — Храните радиологические заключения. Ищите термины (ателектаз, плевральный выпот и др.) для получения понятных объяснений.
- **Лекарства** — Текущие и прошлые препараты, аллергии, печатный список лекарств.
- **Профилактика** — Автоматически выявленные пробелы в медицинской помощи, клинические рекомендации (диспансеризация/USPSTF/ADA), прививочный сертификат.
- **Спросить мою карту** — Общайтесь с подтверждёнными данными о здоровье через ИИ (по умолчанию отключено).
- **Настройки** — Профиль, страна/организация рекомендаций, конфигурация ИИ, модули, экспорт/удаление данных.

## Установка

```bash
git clone <url-репозитория>
cd SelfPatientRecord
npm install
cp .env.example .env
npm run dev
```

- Веб-приложение: http://localhost:5173
- API-сервер: http://localhost:3001

### Переменные среды (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3001` | Порт API-сервера |
| `AI_ENABLED` | `false` | Включить функции ИИ (`true`) |
| `AI_API_KEY` | — | API-ключ, совместимый с OpenAI |
| `AI_BASE_URL` | `https://api.openai.com/v1` | Конечная точка API |
| `AI_MODEL` | `gpt-4o-mini` | Название модели |

Все основные функции работают без ИИ.

## Отказ от ответственности

HealthBinder — инструмент для личной организации медицинских данных. Не является медицинским изделием и не заменяет профессиональную медицинскую помощь. В экстренных ситуациях звоните 112 (единый номер экстренных служб).
